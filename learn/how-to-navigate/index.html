How to Navigate the Course

Start with the Course Overview, then choose a module from the course contents. Within each lesson, use the Previous and Next links at the bottom of the page to move through the sequence.

The Contents menu remains available from the sidebar or the mobile menu. The Reference Shelf collects the course’s sources; required reading is identified separately from optional links.

No login is needed. The site does not ask for an email address or store individual learner records.
